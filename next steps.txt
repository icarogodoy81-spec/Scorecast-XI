Current Save Logic
The save button currently does not persist to Supabase yet.

It only logs the prediction:

ts


console.log('Prediction to save:', {
  fixtureId,
  homeTeam,
  awayTeam,
  homeScore,
  awayScore,
});
Then it marks the prediction as saved locally in state.

So prediction saving is currently frontend-only.
